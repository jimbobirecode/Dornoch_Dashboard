# Assets

## Club logo

Drop the Royal Dornoch logo in here as `dornoch-logo.png`.

- A **white / light** mark works best: it sits on the Sea Slate (`#2B4048`)
  header in both the dashboard sidebar and the outbound emails.
- PNG with a transparent background, roughly 480px wide (it renders at 240px).
- Override the path with the `LOGO_PATH` environment variable if you name it
  something else.

Until the file exists the dashboard and the emails fall back to the club name
set as a text wordmark, so nothing renders as a broken image.
